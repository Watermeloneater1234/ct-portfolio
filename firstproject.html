My First Project

My Website

This is my first ever project only using Html and css to create a website

My Reflection

Creating my website was a process that involved both planning and problem solving(fixing mistakes in the code) rather than just making pages like canva or google slides. At the start I focused on the design and layout(also how they can access different pages). I drew these in my computing tech book and then later incoporated it using css and html. I decided to keep the design simple and clean so it would be easy to use and visually clear. This led me to organise my content into clear sections and use consistent colours and fonts throughout the site.

During development, I used HTML to structure the content and CSS to control the design and layout. One key decision I made was to use responsive design so the website would work on different screen sizes(flex wrap). This is really helpful as it suits all users on all sorts of devices(eg if your on your phone it automatically thrinks your website to something that can accommodate a phone)

I used visual studio code as my editor which helped me stay organised and quickly spot errors in my code. Using git and github was also a extremely as if i messed up i can just return it to the previous version. At first, I found version control confusing, but over time I learned how to commit changes and track my progress.

In the future I would like to improve my website by adding more advanced features, such as animations or interactive elements using JavaScript. I would also improve the design by making it more visually engaging and refining the responsiveness further for different devices(eg flex wrap).

Overall, this project helped me understand the full process of creating a website, from planning to development and improvement, and showed me how much I’ve progressed in my coding skills. I hope the projects to come are just as fun and challenging as this one
